# Gruvbox Color Schemes for KDE Plasma

A collection of 12 [Gruvbox](https://github.com/morhetz/gruvbox)-inspired color schemes for KDE Plasma.

## Theme Variants

The repository contains 12 `.colors` files covering all combinations of:
* **Base:** Dark & Light
* **Accents:** Red & Orange
* **Contrasts:** Hard, Medium, & Soft

## Installation

1. Download or clone this repository.
2. Open **System Settings** in KDE Plasma.
3. Go to **Colors & Themes** ➔ **Colors**.
4. Click **Install From File...** in the top right.
5. Select any `.colors` file and click **Apply**.
